# Exploring global health data assignment
My first python-based project completed as part of degree for MSc Health Data Science in the module 'Introduction to programming for data science'. Jupyter notebooks was used to create the report which was then converted to pdf for submission purposes.

This is a university MSc project in which the task was to analyse a dataset on non-communicable diseases and risk factors obtained from the World Health Organisation following the assignment brief. I opted to focus on Gender Disparities in my project, exploring differences in health estimates between males and
females in the given data.

This dataset contained information on the following factors:
health-related factors, including lifestyle behaviours (e.g., smoking and physical activity),
treatment access (e.g., hypertension treatment), and health outcomes (e.g., probability of dying
from chronic diseases), across various demographic and income groups. 

## Assessment task description

Assignment aims

  to evaluate understanding and application of the following:
  1- Fundamental Data Types & Programming Concepts: Knowledge of core data types,
  structures, and key programming concepts such as iteration, selection, file handling,
  and control flow.
  2- Data Storage & Access: Understanding how data is stored, accessed, and manipulated
  in different formats.
  3- Python for Data Science: Proficiency in using Python for data science, including
  commonly used libraries and modules.
  4- Data Manipulation & Pre-processing: Skills in cleaning, imputing, encoding,
  transforming data, and combining datasets for analysis.
  5- Communication of Data Science Analyses: Ability to effectively communicate analysis
  results to different audiences.
